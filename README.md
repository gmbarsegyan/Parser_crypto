# P2P Exchange Rates Parser

Welcome to the P2P Exchange Rates Parser repository! This project provides open-source code for automatically parsing P2P exchange rate data from three major cryptocurrency exchanges: **Bybit**, **Bitget**, and **Huobi**.

## Purpose
This repository is designed for:
- Individuals involved in P2P arbitrage.
- Investors seeking insights and opportunities using real-time exchange rate data.

## Features
- Automatic data collection from multiple exchanges.
- Support for analyzing P2P exchange rates for arbitrage opportunities.

Feel free to contribute, suggest improvements, or use the code for your own projects. Happy parsing!
